# 🎨 Exercise 1 — Dynamic Color Palette with JSON

A simple JavaScript project that dynamically generates a color palette using JSON data and DOM manipulation.

This exercise is part of Unit 5 and focuses on creating HTML elements, applying CSS styles through JavaScript, and displaying structured data.

## 📌 Project Description

The application reads a JSON object containing information about different colors and dynamically creates HTML elements to display them.

Each color section includes:
- Color name.
- Color category.
- Color type (when available).
- RGBA color code.
- HEX color code.

The background color of each section is automatically assigned using its HEX value.

## ✨ Features

- Dynamic HTML element generation.
- JSON data management.
- DOM manipulation using JavaScript.
- Automatic background color assignment.
- Conditional text color formatting.
- Display of HEX and RGBA color codes.
- Iteration through arrays using `for...of`.
- No external libraries or frameworks.

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Webpage structure |
| JavaScript | DOM manipulation and dynamic content |
| JSON | Structured color data |
| CSS | Dynamic styling through JavaScript |
