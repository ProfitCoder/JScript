# Declaración del var

var nombre = "Pablo";

console.log(nombre);

# Declaración con let

let edad = 19;

console.log("Edad 1: " + edad);

edad = 23;

console.log("Edad 2: " + edad);

# Declaración de const

const pais = "España";

pais = "Italia";

console.log(pais);

Esto, nos va a devolver de pais Italia, porque al poner, esta sentencia "pais = "Italia";" se esta volviendo a asignar un valor.

# Uso de Bloques

{
    var x = 10;
}

{
    let y = 20;
}
 
    La diferencia de los dos bloques es que el var existe dentro y fuera del bloque
    y el let solo existe dentro del bloque y ya esta
